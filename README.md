# Predictive Data Modeling & House Price Estimator

An end-to-end machine learning regression workflow built in Python to predict residential property values from structured tabular data.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib

## Key Workflow Steps
1. **Data Cleaning:** Handled missing entries using median imputation and encoded categorical variables using One-Hot Encoding.
2. **Feature Scaling:** Standardized numerical distributions using `StandardScaler` to ensure uniform feature weighting.
3. **Model Training:** Trained a Linear Regression model on an 80/20 train-test split.
4. **Evaluation:** Assessed model accuracy using Mean Squared Error (MSE) and R-squared ($R^2$) metrics.
